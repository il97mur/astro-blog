# Fastfood Delivery Store

The customer-facing part of an online fastfood store: cart, checkout, dynamic filtering by category and promotions, integrated with a Laravel backend over REST API.

Cached the product catalog and categories in the Vuex store, since that data rarely changes — avoided re-fetching it on every navigation, **cutting server requests by 40%**.

Worked in a team of 3 frontend developers, took part in code review and task planning.
